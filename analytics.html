⚙️ Configurar Google Analytics 4 (una sola vez)

Para datos reales necesita conectar GA4:
1. Cree una cuenta en analytics.google.com → Nuevo sitio web → juridicosweb.com
2. Copie el Measurement ID (formato G-XXXXXXXXXX)
3. En el index.html reemplace G-XXXXXXXXXX por su ID real
4. En GA4 → Eventos: verá consulta_iniciada, formulario_enviado, pago_iniciado, pago_confirmado

Mientras tanto este dashboard muestra los datos de este navegador (localStorage).
